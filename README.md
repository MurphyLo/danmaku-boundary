# 视频标注工具 - Camera Shot Boundary Detection

这是一个用于视频镜头切换（Camera Shot Boundary Detection）任务标注的工具，支持单次切换标注和渐变切换的标注。

## 功能特性

1. 支持两种标注模板：
   - 单次标注：表示场景直接切换
   - 对标注：表示渐变或动画切换，需要标记开始和结束

2. 视频导航功能：
   - 播放/暂停
   - 进度条拖动
   - 键盘快捷键导航

3. 标注保存与加载

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

运行主程序：

```bash
python danmaku_annotator.py
```

### 打开视频

通过菜单栏的"文件 > 打开视频"选项打开需要标注的视频文件。

### 视频导航

- **播放/暂停**：点击播放/暂停按钮或按空格键
- **进度条**：拖动进度条定位视频
- **快捷键**：
  - 右/左箭头：快进/退5秒
  - Alt + 右/左箭头：快进/退1秒
  - Shift + 右/左箭头：快进/退5帧

### 标注操作

1. **单次标注**（直接切换）：
   - 按钮：点击"切换"按钮
   - 快捷键：Ctrl+1

2. **渐变标注**（开始和结束需成对）：
   - 渐变开始：点击"渐变开始"按钮或按Ctrl+2
   - 渐变结束：点击"渐变结束"按钮或按Ctrl+3

3. **删除标注**：
   - 选中标注列表中的项目，点击"删除标注"按钮

### 保存与加载

- **保存标注**：点击"保存标注"按钮，标注将保存为JSON格式
- **加载标注**：打开视频时会自动尝试加载同名的标注文件（xxx_annotations.json）

## 标注文件格式

标注文件使用JSON格式保存，包含以下信息：

- 视频文件信息（文件名、总帧数、帧率等）
- 标注列表，每项包含：
  - 类型（cut/fade_start/fade_end）
  - 帧位置
  - 时间点
  - 时间戳
  - 配对关系（对于渐变标注）
